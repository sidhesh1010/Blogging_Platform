Project Overview

About BlogSphere

BlogSphere is a full-stack, enterprise-grade blogging platform developed as part of an intensive 8-week technical internship program.

Our Objective & Philosophy

Writing and knowledge-sharing should be effortless, fast, and accessible. BlogSphere is designed to bridge the gap between technical documentation and expressive narrative writing.

Rather than relying on heavy bloated frameworks, BlogSphere demonstrates the raw elegance and power of the Python Flask ecosystem paired with clean modular software architecture.

Secure by Default

Password hashing, CSRF protection, and session security.

Blazing Performance

Optimized SQLite queries and clean CSS rendering.

Technology Stack
Backend Python 3.12, Flask 3.0, Werkzeug
ORM & Database Flask-SQLAlchemy, SQLite (Dev), PostgreSQL (Prod ready)
Auth & Forms Flask-Login, Flask-WTF, WTForms, email-validator
Frontend HTML5, Jinja2 Templates, Bootstrap 5.3, Custom CSS
Repository sidhesh1010/Blogging_Platform
Milestones

8-Week Internship Development Roadmap

A methodical, industry-aligned roadmap executed week-by-week without skipping stages.

Week 1 Completed
Flask Setup & Structure

Virtual environment, Application Factory pattern, SQLite & SQLAlchemy setup, base templates, and static assets.

Week 2 Completed
User Authentication

User model, registration, login/logout with Flask-Login, Werkzeug password hashing, CSRF protection, and user profile.

Week 3 Completed
Blog Post CRUD

BlogPost model, rich text editor integration, create, read, update, delete functionality with owner restrictions.

Week 4 Completed
Frontend & UX Polish

Medium-inspired clean layout, responsive blog cards, interactive reading interface, and mobile navigation enhancements.

Week 5 Completed
Commenting System

Comment model with relational foreign keys, user feedback threads, comment editing, deletion, and author moderation.

Week 6 Completed
Search & Filtering

Full-text search by title/content, category and tag filtering, pagination, and preserved search state.

Week 7 Next Milestone
Testing & Deployment

Automated tests with pytest, environment configuration, production database migration, and deployment guide.

Week 8 Final Milestone
Internship Showcase

5-7 minute demonstration video, architecture walkthrough, documentation, learning outcomes, and final submission.
